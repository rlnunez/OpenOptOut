# User & Family Guide

Welcome to the **OpenOptOut User & Family Guide**. This guide is designed for individuals, families, and community members using OpenOptOut to remove their personal information from data brokers and people-search sites.

---

## Getting Started

1. **[Setting Up Your Family Email](email-setup.md)**  
   Learn how to configure plus-addressing, separate privacy inboxes, and email tracking so data broker confirmation messages are captured automatically.

2. **[Web Search Integration](web-search.md)**  
   Find out how OpenOptOut scans private search engines (such as SearXNG) to automatically locate your exposed profiles across hundreds of broker sites.

3. **[Discovering Privacy Request Pages](privacy-pages.md)**  
   How the system identifies OneTrust, TrustArc, and custom opt-out forms across the web.

4. **[Verification & Monitoring](verification.md)**  
   Removing your records is only the first step. Learn how OpenOptOut runs scheduled verification checks to alert you if a broker re-adds your profile.
