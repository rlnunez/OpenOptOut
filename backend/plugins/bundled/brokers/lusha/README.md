## What happens

Lusha deletes the details permanently once the form is sent. For several records at once, write to privacy@lusha.com.

## The checklist steps

> Open https://www.lusha.com/privacy-center/request-removal/ and send a removal request for {full_name} with each of these addresses and numbers: {all_emails}; {all_phones}. Use {contact_email} for replies. Then press "I've done this".
