## What happens

CallerSmart proves you own the number with a code sent to that phone, so whoever has the phone has to finish it. Changes usually show within 3 days.

## The checklist steps

> Open https://www.callersmart.com/data. For each of these numbers, enter the number and {contact_email}, finish the robot check, then type the 6-digit code CallerSmart texts or calls to that phone: {all_phones}. Then press "I've done this".
