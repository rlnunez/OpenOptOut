## What happens

Hiya handles requests per number and allows up to 30 days. A full data deletion request uses its separate advanced data request form.

## The checklist steps

> Hiya supplies caller ID to many Samsung phones and carrier apps. Open Hiya's request form at https://hiyahelp.zendesk.com/hc/en-us/requests/new?ticket_form_id=33394399463699 and ask Hiya to remove the caller ID name for each of these numbers: {all_phones}. Use {contact_email} as your email. Then press "I've done this".
